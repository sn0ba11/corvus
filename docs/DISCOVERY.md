# Account and web discovery

[Documentation index](INDEX.md)

Corvus selects collectors according to the case identifier type. The [collector catalogue](COLLECTORS.md) describes the available adapters and requirements.

## Account searches

Standard username searches combine general discovery tools with native public-profile lookups. The extended username search adds broader Maigret coverage and Naminter/WhatsMyName; this is slower and may produce more inconclusive results. Blackbird requires a separately obtained compatible installation.

Account evidence is grouped by platform and account identifiers while retaining source records. Validate accounts checks profile existence separately from identity linkage. A confirmed account is not proof that it belongs to a particular person. Review the underlying sources before accepting a correlation.

## Name and web searches

Name cases use bounded name variants and relevance-filtered search results. The Search query workbench offers deterministic query packs, reusable templates and explicit result imports. Search-engine hits remain leads. Failed or challenged searches can be reviewed through the managed browser; do not treat a block as a negative result.

## Email and phone

Email and phone workflows include public-directory and optional presence checks, subject to configuration and upstream restrictions. Some checks use account-recovery or presence interfaces and warrant particular care. Use only proportionate, authorised checks; an unresolved response is not evidence of absence. The offline phone adapter provides local number information without establishing subscriber identity.

## Follow-up and interpretation

Corvus can present suggested pivots and bounded automatic follow-ups based on corroboration. Review the source and relevance of proposed relationships before using them. Retain contradictory evidence.
