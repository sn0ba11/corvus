# Investigation management

[Documentation index](INDEX.md)

Create a case from the dashboard. Supply a primary username, full name, email address, phone number or domain. Confirm the detected type; dotted handles can otherwise be interpreted as domains. Use Collection and case options to set a title, reference, notes, tags and appropriate collector selection.

Additional known identifiers can be included in the same case (up to eight additional values per batch). This groups evidence for review; it does not establish common ownership. On a completed case, Add what else you know queues further compatible searches without discarding earlier findings.

## First case

1. Start with synthetic or otherwise authorised data.
2. Select the compatible collectors needed for the task; deselect unnecessary external requests.
3. Start the investigation and watch Activity and Detailed tool runs.
4. Review positive findings, then switch to All statuses to examine unresolved, blocked, failed and negative results.
5. Check source URLs and raw evidence. Validate accounts where appropriate.
6. Record analyst notes, review correlation candidates and preview the report.
7. Export the required evidence before deleting or archiving a case.

Collectors have independent timeouts and outcomes. A failed collector does not invalidate completed runs. Retry an unsuccessful collector from its run details rather than repeating the entire case. Cancel active work before deletion.

## Comparing cases

The case comparison view accepts two to five finished cases and presents shared evidence. Shared values are leads, not proof of identity. Keep separate cases where the relationship between subjects is uncertain.
