# Privacy

Corvus processes investigation data locally. It does not include telemetry and does not send data to third-party AI services. Upstream tools necessarily contact public services relevant to a selected search; review each upstream and applicable service terms before use.

Queries, notes, results, errors, tool versions and raw-output references are stored in the local SQLite volume. Normal application logs omit queries unless explicitly enabled. Live lines replace the query and common secret patterns before reaching the browser. Proxy credentials are configuration-only and excluded from investigation exports.

When the managed browser is enabled, its named profile volume stores cookies and authenticated sessions, while the evidence volume stores screenshots, bounded HTML and manifests from explicitly approved pages. Credentials and cookies are not copied into SQLite, logs or reports, and no browser content is sent to cloud AI or CAPTCHA services. Treat both volumes as case-sensitive local data and the profile volume as a credential store.

Holehe checks account-recovery endpoints and can be intrusive or rate limited. It is visibly labelled, individually selected, disabled from bulk operation, and limited to one run. The system does not implement breach-corpus search, credential disclosure, credential validation, password recovery, credential stuffing, CAPTCHA bypass or automatic IP rotation.

If selected, the phone-presence collector sends the case number to Snapchat. Amazon is also available through an explicit platform setting. Treat external responses as leads.

Operators are responsible for lawful authority, proportionality, retention periods, service terms and data-subject obligations. Use the smallest set of tools needed and delete or archive investigations according to the applicable case policy. Dashboard bulk deletion requires explicit selection and typed confirmation, refuses active investigations, removes case database records plus raw collector and browser-capture directories, and retains only a minimal deletion audit event.
