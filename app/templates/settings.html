OFFICIAL COMPANY REGISTER

UK Companies House API

{{ 'configured' if companies_house_configured else 'disabled' }}

Enables the manual Companies House collector for bounded public company and officer searches, including a small appointment sample for officer matches. The API key is stored locally and never echoed into evidence or logs.

When configured, the collector appears for compatible name investigations but remains unchecked by default.

IP REPUTATION

AbuseIPDB API

{{ 'configured' if abuseipdb_configured else 'disabled' }}

Adds a passive 90-day AbuseIPDB check to the explicit infrastructure enrichment card. Corvus does not submit abuse reports and does not request verbose reporter comments.

PHISHING INTELLIGENCE

OpenPhish authorised feed

{{ 'configured' if openphish_configured else 'disabled' }}

Enables passive domain correlation against an OpenPhish feed your organisation is authorised to use. Corvus deliberately does not default to the public Community feed because its terms restrict organisational operational use. Law-enforcement users can request Gov Feed access from OpenPhish.

When configured, OpenPhish appears as a manual domain collector and matches locally cached feed data without visiting the suspected phishing URLs.

HISTORICAL URL DISCOVERY

URLScan API

{{ 'configured' if urlscan_configured else 'disabled' }}

URLScan is a specialist, manual-only domain collector. Corvus uses the historical Search API only; it never submits a new scan. The API key is not written to case evidence or execution logs.

When configured, URLScan appears in compatible domain collectors but remains unchecked by default.
