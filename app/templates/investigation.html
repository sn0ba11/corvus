Validate EU VAT number

Capture TikTok video evidence

Acquire one publicly accessible TikTok post as an MP4 with metadata, acquisition timestamp, SHA-256 hashes and a verifiable ZIP. Maximum video size 12 MiB; no authentication, comments or bulk collection.

Extract public video metadata

Use the isolated yt-dlp collector to retain metadata without downloading the media file. Supported inputs are YouTube, Vimeo, X/Twitter, Reddit, Facebook and direct TikTok video URLs. TikTok may reject unauthenticated extraction; a failed request is not evidence that a post does not exist.

Metadata-only: no video or audio payload is intentionally downloaded.

Import Telegram Desktop export

Parse an analyst-supplied Telegram JSON export locally. Message dates, senders, IDs, replies, links, usernames, email/phone strings and attachment references are retained without contacting Telegram.

Maximum 20 MiB / 5,000 messages per import; excess messages are explicitly marked truncated.

Import Discord chat export

Parse an analyst-supplied DiscordChatExporter JSON export locally. Message dates, authors (including offline account-creation time derived from their Discord ID), replies, mentions, links, usernames, email/phone strings and attachment references are retained without contacting Discord. Export using a bot token, not a user token, per Discord's terms.

Maximum 20 MiB / 5,000 messages per import; excess messages are explicitly marked truncated.

Import Discord archive (discrawl SQLite)

Parse an analyst-supplied discrawl-compatible SQLite archive locally. Guild, channel, message, mention and attachment records are read directly from the archive; no network request is made and the file is validated against the expected schema before use.

Maximum 150 MiB file / 5,000 messages per import; excess messages are explicitly marked truncated.
